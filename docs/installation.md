# Installation Instructions

1. Go to **Settings > Devices & Services** in Home Assistant.
2. Click **Add Integration** and search for "Samsung Climate".
3. Enter the IP address of your AC unit.
4. If a token is required, follow the on-screen instructions to pair by turning the AC unit on/off when prompted.
5. The integration will automatically map MAC addresses to maintain connection stability even if the local IP changes using DHCP ARP resolution.
