# Entities and Mappings

The `climate_ip` integration sets up the following components:

- **Climate Entity**: Main entity displaying current temperature, target temperature, HVAC mode (Heat, Cool, Auto, Dry, Fan_only), Fan speed, and Swing modes.
- **Sensors**: Diagnostic sensors including compressor speed, current power usage (if supported by hardware), and operational errors.
- **Switches**: Toggles for secondary operations like Purify, Auto-Clean, and Display Beep.
